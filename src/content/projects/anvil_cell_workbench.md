**Anvil Cell Workbench** is a focused quality-of-life addon for *Applied Energistics 2 Unofficial Extended Life* that introduces a new block: the Anvil Cell Workbench. It merges the vanilla anvil’s renaming behavior directly into AE2’s Cell Workbench, allowing players to name and manage storage cells in one place.

This mod exists to eliminate a small but constant friction point in technical play: bouncing between blocks just to label storage media. By embedding renaming into the AE2 workflow, it keeps players in-context and speeds up large-scale storage organization.

### Key Features
- Adds a new **Anvil Cell Workbench** block
- Brings vanilla anvil renaming directly into the AE2 Cell Workbench
- Seamless UI integration with AE2’s existing workbench interface
- Optional **Auto Focus** mode that automatically selects the rename field when opening the GUI
- Drop-in compatibility with existing AE2 setups

### Technical Highlights
- Implemented as an extension of AE2 Unofficial Extended Life
- Hooks into AE2’s cell editing pipeline while preserving expected behavior
- Cleanly layers new functionality without altering core AE2 mechanics
- Designed to feel “native” to AE2, both visually and behaviorally

Anvil Cell Workbench is open-source (LGPLv3)
