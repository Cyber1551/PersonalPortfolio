**EnhancedP2P** is an improved fork of *Better P2P* for *Applied Energistics 2*, focused on making large-scale network routing clearer, faster, and more human-friendly. It enhances AE2’s Point-to-Point tunnel system by adding meaningful naming, search, and UI improvements—turning what is normally an opaque, coordinate-driven workflow into something readable and manageable.

In complex ME networks, P2P tunnels often become a maze of unlabeled endpoints. EnhancedP2P reframes that experience around intent instead of location, letting players name, search, and bind tunnels by purpose rather than by memory.

### Key Features
- Custom P2P names via AE2 nameplates, quartz knife, vanilla anvil, or my custom [Anvil Cell Workbench](/projects/anvil_cell_workbench)
- Search support for named P2P devices in the binding UI
- Removes coordinate display to make room for long, descriptive names
- Fully compatible with existing Better P2P behavior and workflows

### Technical Highlights
- Forked and extended from the Better P2P codebase
- Integrates directly with AE2’s P2P binding and UI systems
- Modifies rendering and interaction layers to support rich metadata
- Preserves upstream behavior while adding forward-compatible features

EnhancedP2P is open-source (GPLv3)
